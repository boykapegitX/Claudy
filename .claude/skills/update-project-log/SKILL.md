---
name: update-project-log
description: Append a timestamped entry to CLAUDE.md's Project Log, Update Log table, and File Index. Use when the user completes a deliverable, creates a new file, or makes a notable change to the project.
---

When updating the project log in CLAUDE.md:

1. **Update Log table** — append a new row with today's date (YYYY-MM-DD HH:MM format) and a one-line summary of what changed.
2. **File Index table** — if a new file was created, append a row with the filename, creation date, and a short description.
3. **Project Log section** — if the change is significant (new deliverable, new research, new tool or integration), add a `###` subsection under `## Project Log` with a brief narrative entry.
4. Never rewrite or delete existing entries — append only.
5. Keep descriptions concise (one line per table row, 2–4 sentences per narrative entry).
